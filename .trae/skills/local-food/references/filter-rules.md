# 筛选规则（按顺序执行）

1. **距离**：默认 1000 米内；同行有长辈或膝盖不好 → 800 米内。
2. **营业状态**：高德标了「暂停营业」「已关闭」的直接去掉；拿不到营业状态的保留，但回复里提醒用户确认。
3. **偏好**：
   - 记忆里有「不吃辣」「清淡」→ 去掉川湘菜、火锅、烧烤。
   - 同行有长辈 → 优先有座位、不用长时间排队的正餐店或茶馆；去掉网红排队店。
   - 同行有孩子 → 优先有小吃、甜品，环境不吵。
4. **多样性**：3 个推荐尽量不同类型（例如 1 家杭帮菜 + 1 家小吃/面馆 + 1 家茶馆）。
5. **排序**：距离近的在前；距离差不多时，评分高的在前（高德有评分时）。

离线兜底：高德不可用时，使用 `restaurants-cache.md` 里的示例数据，并在回复中注明「信息可能已变化」。
