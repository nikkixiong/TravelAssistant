# 行程呈现

## 两种卡片

| kind | 什么时候 | 内容 |
|---|---|---|
| plan | 行程确定后，用户要导出、分享、导入高德 | 时间线、每段交通、步行总量、「在高德查看全部站点」和逐段导航链接 |
| recap | 行后，用户要「回忆」「游记」 | 今天去了哪些地方、一句话记忆点、步行总量，配一段 30 秒左右的语音小结 |

## 步骤

1. 确认当前有行程（没有就说「还没有行程，要不要先排一份」）。
2. `kind=recap` 时：先写一段 80–120 字的口语化小结（只用行程里真实发生的站点，不编造经历），用 `tts_speak` 合成（`kind: chat`）。
3. 调用 `render_trip_card`，`kind` 填 plan 或 recap，recap 时把小结放进 `summary`、音频地址放进 `audio_url`。
4. 回复卡片链接，一句话说明可以转发给同行人。

## 规则

- 「一键导入高德」只生成高德官方的 URI 链接（uri.amap.com），用户点开后在高德里确认，不代替用户操作。
- 卡片模板在 `assets/card-template.html`，用 `{{变量}}` 占位，不要在卡片里放广告。
