# 雨天备选

> 原则：同区域就近替换，减少雨天移动；室内站至少占一半。

| 原景点（户外） | 区域 | 雨天替换 | 距离感 | 说明 |
|---|---|---|---|---|
| 断桥残雪 / 白堤 / 平湖秋月 / 孤山 | 北山 | 浙江省博物馆孤山馆区 | 步行可达 | 周一闭馆，需预约 |
| 曲院风荷 / 岳王庙 | 北山 | 岳王庙（正殿室内为主） | 步行可达 | |
| 苏堤春晓 / 三潭印月 | 湖中 | 雷峰塔 | 打车 10 分钟内 | 游船雨天可能停航 |
| 花港观鱼 / 太子湾公园 / 净慈寺 | 南线 | 雷峰塔 / 中国丝绸博物馆 | 步行或短途打车 | 丝绸博物馆周一闭馆 |
| 龙井村 / 九溪烟树 | 龙井 | 中国茶叶博物馆 | 打车 10 分钟内 | 茶博周一闭馆 |
| 城隍阁 | 吴山 | 杭州博物馆 | 步行可达 | 周一闭馆 |
| 河坊街 / 南宋御街 | 吴山 | 湖滨步行街（湖滨银泰） | 打车 10 分钟内 | 商场可避雨 |

雨天提醒话术：
- 「雨天石板路滑，长辈走慢点。」
- 「游船可能停航，三潭印月今天先不去了。」
