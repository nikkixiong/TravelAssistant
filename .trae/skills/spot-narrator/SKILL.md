# 景点讲解

## 步骤

1. **确定景点**：用户说了名字就用名字；没说时，按顺序推断：当前情境里的位置 → `amap_regeocode` 逆地理编码 → 行程里当前时间对应的那一站。都不确定就用 `ask_user` 问一句（带 2–3 个候选景点做选项）。
2. **选风格**：`memory_get` 看同行人：有长辈 → `elder`；有孩子 → `kids`；否则 `default`。各风格写法见 `references/styles.md`。
3. **先查缓存**：调用 `tts_speak`，只传 `cache_key`（`景点名:风格`，例如 `断桥残雪:elder`），不传 `text`。
   命中就直接用返回的 `text` 和音频，跳到第 7 步——热门讲解是预生成好的，零成本、零等待。
4. **读知识卡**：`read_skill_file("spot-narrator", "references/narration-kb/index.md")` 找到对应文件，再读那份知识卡。
   - **知识卡里没有的年代、人名、数字一律不讲。**
   - 没有这个景点的知识卡：只讲高德能查到的名称、位置，然后说「这里的历史我手头没有可靠资料，就不乱讲了」。
5. **写讲解稿**：250–350 字，口语化，结尾给一个「现在可以做的事」（拍照角度、看哪里）。
6. **合成语音**：调用 `tts_speak`，带上 `text`、`kind: "narration"`、`style` 和同一个 `cache_key`。
   失败时只返回文字稿，并告诉用户「语音暂时不可用，先看文字」。
7. **回复**：直接给讲解稿（不要再加「以下是讲解」这类开场白）。

## 用户追问具体历史问题

- 答案在知识卡里 → 用一两句话回答，可以不合成语音。
- 答案不在知识卡里 → 回答「这个我不确定，景区的导览牌上会有」，不要猜。

## 禁止

- 编造传说出处或历史年份
- 把传说说成史实（知识卡里标了「传说」的，讲的时候也要说「传说」）
- 在讲解里推销商家
